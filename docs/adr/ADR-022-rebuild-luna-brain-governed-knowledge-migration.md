# ADR-022 — Rebuild Luna Brain V2, Port Governed Knowledge, Not Runtime State

Status: DECIDED architecture direction; implementation NOT STARTED
Date: 2026-10-13
Scope: Light Luna Brain migration from legacy Sentinel, knowledge lifecycle, trust, Cloud sharing
Supersedes: none; complements [ADR-020](ADR-020-go-core-python-optional.md) and [ADR-021](ADR-021-ebpf-observability-xdp-optional.md)
Primary sources: [VPS-ARM source audit](../history/audits/SENTINEL_LUNA_COGNITION_AUDIT_2026-10-13.md), [Brain V2 design](../architecture/luna-brain-v2.md), [Knowledge pipeline](../architecture/threat-intelligence-knowledge-pipeline.md), [Luna Brain mission](../03-LUNA-BRAIN.md)

## Decision

**Build a new Go-native, portable and separately permissioned Luna Brain V2 for Light Luna. Do NOT clone the live Sentinel services/databases or assume they contain transferable trained neural-network weights.** Port the verified semantic contracts, curated network/security knowledge, negative examples and defensible reasoning rules through a versioned offline migration with human review and reproducible tests. Keep the original Luna/Selene instances unchanged.

Distinct data categories:

1. **Authoritative safeguards**: fail-on-missing-data, separation of evidence/identity/intent/impact, site isolation, false-positive safeguards and no self-granted policy authority. Reimplement as tests + Go policy contracts; these are **not learnable weights**.
2. **Curated priors and reasoning recipes**: source-linked, deduplicated facts, hypotheses, counterexamples, network-layer concepts, incident progression, attack taxonomy. Import only after provenance, licensing, quality and review. Historical autogenerated repeats are not independent knowledge.
3. **Heuristic coefficients**: historical 0.65/0.35 blend, 0.94 time decay, feature increments, traffic thresholds and distance limits are **legacy implementation constants, not empirical calibrated probabilities**. Preserve for reproducible shadow replay; do not treat as universal rules or auto-import as live risk weights.
4. **Local observations and memory**: SQLite traffic observations, IP/subnet histories, timestamps, sensitive topology, user labels and production event rows are site-scoped/private. **No bulk copy to public GitHub/Cloud.** Move at most separately consented, minimally necessary, pseudonymized/aggregated evaluation examples with reviewed privacy contract.
5. **Learned model weights**: none were confirmed in Sentinel runtime/source audit. A future local ML model/optional Python worker is a **new train/evaluate/promote process**, not an existing checkpoint migration.

## Three authority planes

- **Knowledge Plane**: versioned, signed/source-hashed public/vendor feeds + private site-enriched asset exposures + curated reasoning/scenario templates. Distinguish global factual advisories from local affected-system proof.
- **Reasoning Plane**: Go deterministic baseline, memory/retrieval, multi-window behavioral correlation and evidence/falsification graph; optional Python ML inference can suggest ranked hypotheses but never grant authorization.
- **Execution Authority Plane**: separate Go Policy Gate and restricted executor for future nftables/WAF/XDP; operators authorize permissions and scope/TTL. Brain cannot directly write firewall/kernel or escalate from Cloud reports.

## Cloud learning decision

The Cloud may aggregate **approved, privacy-minimized, deduplicated and cross-validated attack patterns**, source intelligence, de-identified features and outcome labels, with tenant isolation, opt-in controls, anti-poisoning review, source-version lineage, retractions and rollback. A local node can subscribe to signed/verified knowledge snapshots and reject bad/stale packs. Local actions stay subject to local policy and do not require Cloud availability. **Do not upload raw access logs, unverified client IPs, network topology, user databases or proprietary source code by default.**

Repeated alerts from one feed/host are not independent evidence; Cloud popularity does not imply exploitability or maliciousness. Global observations can prioritize *investigation*, not grant global packet drops.

## Migration protocol (non-destructive)

1. Record exact legacy source identity, file byte hashes, license/provenance, manifest and unique semantic categories; inventory without exporting sensitive state.
2. Produce reviewed deduplicated portable `KnowledgeClaimV1` and `ScenarioV1` candidates; preserve counterexamples, unknowns, evidence gaps and falsification routes.
3. Isolate old heuristic scores as `legacy_shadow_baseline`; compare Go replay against approved benign/adversarial fixtures, including negative controls (authorized scanners, long polls, CDN/proxy, flash crowd, deployment).
4. Create a manually reviewable promotion batch; require minimum reproducibility/recall/false-positive criteria per class, site and action risk. **Never self-promote a ruleset/model to enforcement or widen scope by dataset size.**
5. Deploy only via signed/versioned read-only knowledge snapshots; keep provenance and previous revision for rollback. Hold algorithm and enforcement gates independently.
6. Maintain a private data-migration path separate from public source. Never delete or shrink legacy databases/backups as part of this migration.

## Constraints and status

- P0–P4 independent Host/Edge and G-STANDALONE gate still take precedence. No NetBird connector until explicit later approval.
- Neither real ban authority nor XDP attachment is granted here.
- Legacy Sentinel is maintained as independent observe-only benchmark, not overwritten by Light Luna.
- Brain V2 implementation, weight calibration, Cloud sync, pack signatures and automatic CVE-to-asset proof are **proposed**, not delivered.
