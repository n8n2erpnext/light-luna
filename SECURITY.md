# Security Policy (pre-release)

This repository is an architecture/design baseline. There is no supported security product release, no supported agent binary and no vulnerability disclosure mailbox specifically created for Light Luna yet.

Do not test or deploy these specifications against production firewall rules. Do not include real access logs, API tokens, NetBird peer secret material or customer information in issues or pull requests. For security-related project communication use the organization's existing appropriate private channel until an official disclosure address and process are published.
